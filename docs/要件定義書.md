# スピーチ練習アプリ 要件定義書

Oct 11, 2026 · @user

マイク音声の文字起こしから速さ(文字/分)を計測して3種類の観客スプライトを切り替え、台本やお題文があるモードでは練習後に元の文との一致度を出すWebアプリをTypeScriptで作る。「【未決定】」と書いた箇所は未決定なので、コメントで追記してください。

## 1. システム概要と目的

一人でも話す速さをその場で直せて、台本どおりに話せたかを練習後に確かめられる、ブラウザで動くスピーチ練習アプリ。要求の詳細は要求定義書を参照。

| 項目 | 内容 |
| --- | --- |
| システム名 | 【未決定】(仮称:スピーチ練習アプリ) |
| 形態 | ブラウザで動くWebアプリ(サーバー処理なし) |
| 解決する課題 | 一人の練習では、速さが適切か、台本どおりに話せたかを判断できない |
| ゴール | 速さ250〜350文字/分の範囲で話せているかを数値と観客の反応で伝える。台本がある場合は、練習後に一致度(%)を示す |
| 練習モード | 台本なし / 自分の台本 / お題文(外郎売など) の3つ |
| 対応する要求 | 要求定義書 R-01〜R-11 |
| 対象外 | 声量(dB)の計測と判定、練習中のリアルタイムな一致度表示 |

## 2. システム構成

すべての処理をブラウザ内で行い、自前のサーバーは持たない。外部と通信するのは音声認識だけ。

## 4. 速さの判定と一致度の計算

練習中は速さを3段階に判定して観客スプライトを決め、練習後は台本と文字起こしから一致度を計算する。声量は計測しない。

### 4.1 速さの判定

```latex
\text{cpm} = \frac{\text{対象期間に認識された文字数}}{\text{対象期間の秒数}} \times 60
```

| 判定 | 条件(文字/分) | 値(`SpeedLevel`) |
| --- | --- | --- |
| 遅い | 250未満 | `'slow'` |
| 最適 | 250以上350以下 | `'optimal'` |
| 速い | 350より大きい | `'fast'` |

- 境界値(250、350)は「最適」に含める。
- 文字数は、文字起こし結果(漢字かな混じり)から句読点・空白・記号を除いて数える。ひらがな換算はしない(原稿の目安「1分300字」も漢字かな混じりで数えるため)。
- 対象期間は直近 `SPEED_WINDOW_SEC` 秒とする。【未決定:仮値20秒。短いと値が暴れ、長いと反応が遅れる。テストプレイで10秒では値が小刻みに動いて最適を保ちにくく、観客も頻繁に切り替わったため20秒に広げた】
- 判定と表示の更新は `JUDGE_INTERVAL_MS` ミリ秒ごとに行う。【未決定:仮値1000】
- 黙っているあいだは文字が増えず `cpm` が下がり続ける。そこで、文字が増えないまま `SPEED_SILENCE_SEC` 秒たったら黙っているとみなし、判定を止めて直前の判定を保つ。黙っているあいだの計測値は `samples` に残さず、最適の割合にも入れない。対象期間(直近 `SPEED_WINDOW_SEC` 秒)は黙っていた時間を除いて数える。
- 結果画面の平均速度は、練習全体の文字数 ÷ 黙っていた時間を除いた練習時間で計算する。

### 4.2 一致度の計算

台本モードとお題文モードで、練習終了後に1回だけ計算する。台本なしモードでは計算せず、一致度は `null` とする。

1. 台本と文字起こしの両方を正規化する。句読点・空白・改行・記号を除き、全角と半角の英数字をそろえる。
2. 正規化した2つの文の編集距離(1文字の挿入・削除・置き換えをそれぞれ1と数えた、一方をもう一方に直す最小の回数)を求める。
3. 次の式で一致度を出し、整数に四捨五入する。0を下回る場合は0とする。

```latex
\text{matchRate} = \left(1 - \frac{\text{編集距離}}{\text{正規化した台本の文字数}}\right) \times 100
```

例:台本「こんにちは」(5文字)に対して文字起こしが「こんちは」なら、編集距離は1で一致度は80%。

結果画面では、台本との違いを3種類に色分けして見せる。

| 区分(`DiffType`) | 意味 | 表示(仮) |
| --- | --- | --- |
| `'match'` | 台本どおりに話せた部分 | 通常の文字 |
| `'missing'` | 台本にあるが、文字起こしにない部分(読み飛ばし・誤認識) | 【未決定:色や打ち消し線など】 |
| `'extra'` | 台本にないが、文字起こしにある部分(言い間違い・言い直し) | 【未決定】 |

- 表記ゆれの扱いは【未決定】。漢字かな混じりのまま比べると、台本「拙者」と文字起こし「せっしゃ」のように読みが同じでも不一致になる。両方をひらがなに直してから比べれば防げるが、形態素解析ライブラリが必要になる。
- 台本の途中で練習を終えた場合の扱いは【未決定:仮案は台本全文と比べる。読んでいない部分はすべて不一致になる】
- 一致度の評価(何%以上を「良い」とするか、段階を設けるか)は【未決定】

### 4.3 観客スプライトの対応表(3種類)

スプライトのキーは `audience_{SpeedLevel}` とし、画像ファイル名も同じにする。どのモードでも同じ3種類を使う。観客の見た目は【未決定】なので、コメントで追記してください。

| 速さの判定 | スプライトキー | 画像ファイル | 観客の見た目 |
| --- | --- | --- | --- |
| 遅い(`slow`) | `audience_slow` | `audience_slow.png` | 【未決定】 |
| 最適(`optimal`) | `audience_optimal` | `audience_optimal.png` | 【未決定】 |
| 速い(`fast`) | `audience_fast` | `audience_fast.png` | 【未決定】 |

- 3種類の画像は仮置き(`sprite_normal` に色を付けたもの)。絵ができたら差し替える(UI改修で追加)
- 背景 `sprite_bg.svg` はどの状態でも変えずに出し、その上に観客の画像を重ねる。背景と観客の画像は同じ縦横比(3508:2481)で、そのまま重ねると位置が合う(UI改修で追加)
- 起動時や練習開始直後など、まだ判定が出ていないときは通常の観客 `sprite_normal.svg` を出す(UI改修で決定)
- 観客の人数、画像サイズ、アニメーションの有無は【未決定】

## 5. 機能要件(UI)

画面はホーム・台本設定・練習・結果・履歴の5つ。台本設定は、自分の台本モードとお題文モードでだけ通る。ホームと練習は、観客席の前に立つ「舞台」の画面で、背景と観客の画像を画面いっぱいに出す。起動時は台本なしモードのホームから始まり、練習モードは右上のメニューで切り替える。ビジュアルデザインは参考画像(`参考.png`)に合わせる。フォントは丸みのあるゴシック体の Zen Maru Gothic(Google Fonts)を使う(UI改修で決定)。

### 5.1 画面一覧と項目

| 画面ID | 画面名 | データ項目(表示・入力) | 操作項目 |
| --- | --- | --- | --- |
| SCR-01 | ホーム | 背景と観客(通常)、経過時間(左上)、いまの練習モード、台本があるモードでは台本の本文(「開始」ボタンの上)。起動時に、アプリ名、使い方、マイクと音声送信の注意書きをポップアップで出す | 「開始」ボタン(下の中央)、右上のメニュー(「台本なし」「自分の台本」「お題文」「履歴を見る」「使い方」) |
| SCR-02 | 台本設定 | 自分の台本モード:台本の入力欄、現在の文字数。お題文モード:お題文の一覧(タイトル、文字数)、選んだ文のプレビュー | お題文の選択、「決定」ボタン、「戻る」ボタン |

### 5.3 入力チェックとエラーメッセージ

入力チェックが必要なのは、自分の台本の入力欄だけ。文言は仮。【未決定:最終的な文言】

| エラーコード(`AppErrorCode`) | 発生条件 | 表示メッセージ(仮) |
| --- | --- | --- |
| `'script-empty'` | 自分の台本が空、または句読点や空白だけ | 台本を入力してください。 |
| `'script-too-long'` | 自分の台本が `SCRIPT_MAX_LENGTH` 文字を超えている | 台本が長すぎます。 |
| `'script-not-selected'` | お題文を選ばずに「決定」を押した | お題文を選んでください。 |
| `'mic-denied'` | マイクの使用が許可されなかった | マイクの使用を許可してください。 |
| `'mic-not-found'` | マイクが見つからない | マイクが接続されているか確認してください。 |
| `'speech-unsupported'` | ブラウザが音声認識に対応していない | ChromeまたはEdgeで開いてください。 |
| `'speech-network'` | 通信できず音声認識が止まった | インターネット接続を確認してください。 |
| `'storage-failed'` | 履歴を保存できなかった | 結果を保存できませんでした。 |

## 7. データ要件

扱うデータは、保存する練習記録(`SessionRecord`)と、アプリに内蔵するお題文(`PresetScript`)の2種類。音声そのものは保存しない。

| 項目 | 内容 |
| --- | --- |
| 練習記録の保存先 | `localStorage` にJSON配列として保存(ブラウザごと・PCごとに別。ブラウザのデータを消すと履歴も消える) |
| 保存キー | `STORAGE_KEY = 'speechPractice.sessions'` |
| 保存件数の上限 | `MAX_HISTORY_COUNT` 件。超えたら古いものから消す。【未決定:仮値50】 |
| お題文の置き場所 | `src/data/presetScripts.ts` に配列として書く(保存領域は使わない) |
| 内蔵するお題文 | 外郎売。そのほかは【未決定:種類と本数。外郎売は全文か一部か】 |
| 自分の台本の再利用 | 【未決定:入力した台本を保存し、次回も選べるようにするか。現状は練習記録の中にだけ残る】 |

### SessionRecord の項目

| プロパティ | 型 | 内容 |

### 8.4 型(`src/types.ts`)

```typescript
export type SpeedLevel = 'slow' | 'optimal' | 'fast';

// 例: 'audience_fast'
export type AudienceSpriteKey = `audience_${SpeedLevel}`;

// free: 台本なし / custom: 自分の台本 / preset: お題文
export type PracticeMode = 'free' | 'custom' | 'preset';

export type ScreenId = 'home' | 'script' | 'practice' | 'result' | 'history';

export type AppErrorCode =
  | 'script-empty'
  | 'script-too-long'
  | 'script-not-selected'
  | 'mic-denied'
  | 'mic-not-found'
  | 'speech-unsupported'
  | 'speech-network'
  | 'storage-failed';

// 内蔵のお題文(7章)
export interface PresetScript {
  id: string;
  title: string;
  text: string;
}

// 練習で使う台本。台本なしモードでは null を使う
export interface ScriptSource {
  title: string;
  text: string;
}

// 1回の判定ごとの計測値
export interface MeasurementSample {
  elapsedSec: number;       // 練習開始からの経過秒
  cpm: number;              // 速さ(文字/分)
  speedLevel: SpeedLevel;
}

// 台本と文字起こしの違い(4.2)
export type DiffType = 'match' | 'missing' | 'extra';

export interface DiffSegment {
  type: DiffType;
  text: string;
}

// 一致度の計算結果
export interface MatchResult {
  matchRate: number;        // 0〜100の整数
  segments: DiffSegment[];
}

// 保存する練習記録(7章)
export interface SessionRecord {
  id: string;
  startedAt: string;
  mode: PracticeMode;
  scriptTitle: string | null;
  scriptText: string | null;
  durationSec: number;
  transcript: string;
  charCount: number;
  averageCpm: number;
  speedOptimalRatio: number;
  matchRate: number | null;
  samples?: MeasurementSample[]; // 保存するかは未決定
}
```
