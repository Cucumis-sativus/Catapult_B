# スピーチ練習アプリ 要求定義書

Oct 11, 2026 · @user

話す速さをリアルタイムに計測して観客スプライトの反応で伝え、台本がある場合は練習後に台本との一致度も確かめられるスピーチ練習アプリを作る。「【未決定】」と書いた箇所は未決定なので、コメントで追記してください。

## 1. 作りたいもののイメージ

マイクに向かってスピーチを練習すると、画面の観客が話す速さに応じて反応するWebアプリ。

- 入力された音声を認識し、文字起こしする。
- 話す速さ(1分あたりの文字数)を計測し、画面に表示する。
- 速さの判定結果(遅い・最適・速い)に応じて、観客のスプライトを切り替える。
- 練習モードを3つから選べる。台本なし、自分の台本を入力、アプリ内蔵のお題文(外郎売など)から選ぶ。
- 台本やお題文があるモードでは、練習後に元の文と文字起こしを比べ、どれくらい一致しているかを表示する。
- 練習結果を端末内に保存し、あとで見返せる。

## 4. 導入前後のフロー

システム化する範囲は、練習中の計測・フィードバックと、練習後の振り返り。原稿作成は範囲外とする。

### 導入前(現状)

1. 原稿を用意する。
2. 一人で声に出して練習する。必要ならスマホなどで録音する。
3. 録音を聞き直すか、他の人に聞いてもらって感想をもらう。
4. 感覚を頼りに速さや声量を直す。

### 導入後

1. 原稿を用意する。(システム外。お題文を使う場合は不要)
2. アプリを開き、練習モードを選ぶ。台本なし、自分の台本、お題文の3つ。
3. 自分の台本なら文章を入力し、お題文なら一覧から選ぶ。
4. マイクの使用を許可して練習を開始し、観客に向かって話す。
5. 速さの数値と観客の反応を見ながら、その場で話す速さを直す。
6. 練習を終了し、結果画面で平均の速さを確認する。台本やお題文がある場合は、一致度と違っていた箇所も確認する。
7. 履歴画面で過去の結果と比べる。

### 今回は対象外とするもの(仮)

- 声量(dB)の計測と判定(チーム内の変更で対象外にした)
- 練習中のリアルタイムな一致度表示(一致度は練習終了後のみ)
- サーバーへの保存、ログイン、アカウント管理
- 話の内容そのものの評価(構成、言葉遣いなど)
- スマートフォン対応【未決定】
